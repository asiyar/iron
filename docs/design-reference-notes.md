# IronPulse Görsel Yeniden Tasarım Notu

## Referans İncelemesi

Appllama, yüksek gelirli iOS uygulamalarından oluşan geniş bir ekran ve akış arşivi sunmaktadır. İncelemede sağlık/fitness kategorisinde WeightBuddy, Cal Scanner AI, Evlo Fitness, Yoga Studio ve Sworkit gibi örneklerin bulunduğu görüldü. Bu kaynak, IronPulse için **tasarım ilhamı** olarak kullanılacak; ekran, varlık veya kod birebir kopyalanmayacaktır.

## IronPulse’a Uygulanacak Özgün Görsel Yön

| Alan | Uygulama kararı |
|---|---|
| Tipografi | Sayısal performans metriklerinde daha geniş, büyük ölçekli bir hiyerarşi; destek metinlerinde daha sıkı ve sakin ton |
| Katmanlar | 20–24 px köşeli, düşük kontrast yüzey katmanları; ana eylemde lime yeşili yerine kontrollü vurgular |
| Hareket | Set tamamlama, dinlenme durumu ve metrik güncellemesinde 120–220 ms’lik kısa anlamlı geçişler |
| Bilgi mimarisi | Bugün ekranında tek baskın eylem; Aktif Antrenman’da set odaklı yoğunluk; Performans’ta özet → içgörü → araç dizilimi |
| Özgünlük | IronPulse’ın koyu atletik paleti, GLB kas atlası ve performans dili korunur; referans ekranlar yeniden üretilmez |
